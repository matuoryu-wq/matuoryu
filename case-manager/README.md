# 案件管理(個人弁護士向け)

事件・相談を一元管理する、Windows PC 上で動く Web アプリ。iPhone・Windows のブラウザから
Tailscale 経由で利用する。セットアップは [docs/SETUP.md](docs/SETUP.md)。

## 期限計算について

- 計算ルール: 民訴法95条(家事・非訟も準用)/刑訴法55条/民法140〜143条。
- 末日の休日: 日曜・土曜・祝日法の休日・1月2日・3日・12月29日〜31日、および画面で登録した休日。
- 祝日は 2000〜2099 年を法律に従って計算(振替休日・国民の休日・2019〜2021年の特例を含む)。
  春分・秋分は近似式のため、官報公示と異なる場合は「設定 → 追加の休日」で補正する。
- 自動計算で登録した期限は「未確定(計算値)」となり、根拠と計算過程を確認して「確定」するまで
  ダッシュボードで警告し続ける。
- 起算点(送達日・知った日等)の認定、期間伸長、特則の有無は弁護士が判断すること。

## 構成

```
app/            FastAPI + SQLite(標準ライブラリ sqlite3)
  static/       PWA(ビルド不要の HTML/CSS/JS)
tests/          自動テスト(pytest)
  fixtures/     模擬事件セット(架空。わざと雑な入力を含む)
scripts/        バックアップ単発実行・模擬データ投入
start.bat       起動(初回は仮想環境を自動作成)
backup.bat      日次バックアップ(タスクスケジューラ用)
```
